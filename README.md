# Campus-wish-wall
Drop a wish or a goal, watch it turn into a light drifting through a dark field, and let a stranger on campus catch it and write back. Inspired by paperplanes.world, reimagined for our own campus.
No feeds, no likes, no algorithm — just quiet lights and the people willing to reply to them.

Built with Three.js, some late nights, and way too much coffee ☕
